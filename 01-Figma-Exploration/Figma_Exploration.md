# Figma Exploration
## Week 1 – Introduction to HCI & User Experience Workflow

### 1. Introduction
Figma is a web-based design tool used to create user interfaces, wireframes, and prototypes. It helps designers plan and visualize how users interact with applications.

### 2. Objectives
- Understand the Figma design environment.
- Explore existing user interface designs.
- Learn about screens, frames, and layers.
- Understand the importance of usability in interface design.

### 3. Tool Used
**Figma:** A collaborative interface design and prototyping tool.

### 4. Practical Activity
I selected an existing design called **Limester – Food Delivery App** from Figma.

I explored the following five screens:
1. Splash Screen
2. Login Screen
3. OTP Verification Screen
4. Main Menu Screen
5. My Orders Screen

I captured screenshots of these screens and uploaded them to my GitHub repository.

### 5. What I Learned
- How to navigate the Figma canvas.
- How to explore layers and frames.
- How different screens are organized in a mobile application.
- How interface design affects the user experience.

### 6. Conclusion
This practical activity introduced me to Figma and the basic concepts of interface design. I also learned how to explore an existing application design and prepare it for usability evaluation.
